# Phase 1 — Rule reclassification + non-destructiveness guard

## Parent Initiative
[[RIT-I-0020]] — REQ-002, REQ-003, REQ-004, REQ-005, NFR-002.

## Objective
Re-scope the job-independent wording analyzer so it no longer emits/applies `SUMMARY_TOO_LONG`
(length/budget) or `FOUNDATIONAL_SKILL` (job-aware relevance), preserving their detectors as
documented helpers for the perfect/tailored passes; add a content-preservation invariant so the
wording pass can never drop a bullet/skill/role/section or shorten to a length target.

- [x] Detectors preserved as named helpers (`summary_too_long`/`detect_summary_too_long`,
      `foundational_skills`/`detect_foundational_skills`) with downstream-owner docstrings.
- [x] Guard test: refine rule set emits no length/relevance rule for a fixture that formerly triggered both.
- [x] `content_preserved(before, after)` added to scoring (`base_fix.py`, exported) — masks
      summary + experience-bullet wording, compares the rest (roles/skills/bullet counts).
- [x] `build_standard` enforces `content_preserved` alongside `claims_preserved`, refusing the write on drift.
- [x] Table-driven tests: dropping a bullet/skill/role fails; in-place reword passes.
