# Config alias_file pointer + facade/CLI/MCP/API honor project alias path

## Parent Initiative **[CONDITIONAL: Assigned Task]**

[[RIT-I-0009]]

## Objective **[REQUIRED]**

Make the grown alias index benefit EVERY surface, not just the agent (REQ-905). Define an `alias_file`
pointer in the `resume-kit/config.json` convention and ensure the facade + all interface adapters
(CLI, MCP, API, and the job-hunter bridge if it runs ATS/match) resolve that path and hand it to the
deterministic engine (via the RIT-T-0068 hook — explicit arg or by setting `RESUME_KIT_ALIAS_FILE`).

## Implementation Notes **[CONDITIONAL: Technical Task]**

### Recommended Agent
`opus + medium` — Substantive integration across the facade + four adapters that must stay consistent
(parity is a hard requirement) and reuse ONE resolution helper. Follows the established Phase-5 facade/
adapter pattern, so not `high`, but the blast radius (all surfaces) and the parity/determinism
invariants make it more than a single-file change.

### Technical Approach
- Read the existing config.json handling and the facade→adapter pattern from Phase 5/6 (facade package +
  cli/mcp/api). Add the `alias_file` pointer to whatever loads config.json today.
- Prefer passing the resolved path explicitly to the engine hook where the facade already constructs the
  call; use the `RESUME_KIT_ALIAS_FILE` env only if a call path can't thread an arg cleanly — and if so,
  set/reset it in a tight scope to avoid cross-call leakage (determinism).
- Keep resolution in ONE helper to prevent divergence between surfaces (the same anti-divergence posture
  as RIT-I-0008's shared matcher).

### Dependencies
- Depends on: RIT-T-0068 (the engine merge hook + path resolution contract). Must land first.
- Independent of RIT-T-0070 (plugin skills) — file-disjoint (skills are markdown under plugins/); can run
  in parallel with 0070 once 0068 is in.
- Blocks: RIT-T-0071 (integration proof exercises a surface with a project file).

### Risk Considerations
- **Parity drift**: if adapters resolve the path differently, surfaces diverge — enforce the single
  helper + a cross-surface parity test.
- **Env leakage**: setting `RESUME_KIT_ALIAS_FILE` process-wide across calls breaks determinism/tests —
  scope it or prefer explicit args.
- **Working-dir assumptions**: resolve `alias_file` against the resume-kit working dir, not CWD, matching
  the active_resume/active_job convention.
