# Plugin skill: ATS-view report + workflow wiring

## Parent Initiative

[[RIT-I-0017]]

## Objective **[REQUIRED]**

Add a plugin skill that surfaces the "what the ATS sees" report via the new capability, and wire it into
`resume-workflow` at the analysis step so users see the ATS view alongside the structure/match checks.

## Context

The report capability (from [[RIT-T-0109]]) needs a user-facing skill, consistent with the existing
`check-ats-structure` / `check-keyword-match` skills. `resume-workflow` sequences the phases and is where
the ATS-view step belongs (analysis, before improve).

## Acceptance Criteria **[REQUIRED]**

- [ ] New skill (e.g. `show-ats-view` / `check-ats-view`) drives the CLI/MCP capability deterministically,
      following the single-responsibility skill conventions used by the other check skills.
- [ ] The skill presents detected sections, extracted entities + YoE, and the zoned keyword breakdown in a
      readable form, and explains it as "what an ATS parser sees."
- [ ] `resume-workflow` references the skill at the analysis step; any prerequisite gating matches the
      existing pattern.
- [ ] Skill docs are internally consistent (no claims of behavior the capability doesn't have).
- [ ] The skill's presentation includes the standing disclaimer that **an ATS score does not guarantee
      recruiter advancement** (surfacing the note from RIT-T-0109's report), so the skill never implies the
      score is a decision. This is where [[RIT-I-0018]]'s anti-"score guarantees advancement" guidance is
      surfaced — see [[RIT-A-0004]].

## Implementation Notes **[CONDITIONAL: Technical Task]**

### Technical Approach
Copy the structure of an existing check skill (`check-ats-structure`), point it at the new capability, and
add the workflow step. No engine logic here.

### Dependencies
Blocked by [[RIT-T-0109]]. Feeds [[RIT-T-0111]].

### Risk Considerations
Low — documentation/wiring following an established skill pattern.

### Recommended Agent
**sonnet + medium** — single skill authored to a clear existing pattern; reasoning already defined upstream.
