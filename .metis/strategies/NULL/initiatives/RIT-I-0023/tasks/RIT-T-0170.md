# T2: Flow 1 prepare-base-resume

## Parent Initiative **[REQUIRED]**

[[RIT-I-0023]]

## Objective **[REQUIRED]**

Create the standalone `prepare-base-resume` flow. It prepares one resume without needing a job:
parse/faithfulness gate, base structural fixes, canonical no-custom shape, job-independent refine, ATS view,
and durable full-resume learning seeding.

## Acceptance Criteria **[REQUIRED]**

- [ ] New `prepare-base-resume` skill exists with frontmatter and clear gates.
- [ ] The flow can be run when no active job exists.
- [ ] The flow composes the existing primitives: `parse-resume`, `update-structure`, `update-shape`,
      `check-best-practices`, `update-refine`, optional `check-ats-view`, plus the learning seed from
      [[RIT-T-0169]].
- [ ] Output includes a prepared ATS-ready resume artifact with no custom sections in the prepared output.
- [ ] Output includes seeded/merged learning/evidence covering the full source resume.
- [ ] The flow supports preparing multiple resumes without overwriting unrelated existing learning or config
      pointers unexpectedly.
- [ ] README and plugin skill listing mention that this flow is reusable before any job-specific work.

## Implementation Notes **[REQUIRED]**

### Technical Approach
- Prefer a skill/runbook first. Add a thin composite command only if code-owned state updates need one
  stable invocation for tests or user ergonomics.
- Keep `refine` as the default downstream tailoring input after the flow completes.
- If a composite command is added, expose it consistently or explicitly limit it to the facade/CLI with a
  documented reason.

### Dependencies
- [[RIT-T-0169]] for durable learning/evidence seed and no-custom handoff.
- Existing parse/baseline/refine skills and capabilities.

### Risk Considerations
- Do not make Flow 1 job-aware. It prepares the resume and learning base only.
- Do not silently discard ambiguous source content to satisfy the no-custom output requirement.

### Recommended Agent
`sonnet + medium` if skill-only; `opus + medium` if adding composite code across surfaces.

## Verification Steps **[REQUIRED]**

- [ ] Plugin skill markdown tests include `prepare-base-resume`.
- [ ] Flow 1 fixture test proves prepared output has no custom sections and learning contains custom/unmapped
      facts.
