# T6: Complete flow + docs/tests close-out

## Parent Initiative **[REQUIRED]**

[[RIT-I-0023]]

## Objective **[REQUIRED]**

Reconcile the complete end-to-end flow after the four smaller flows exist. `complete-resume-flow` should
sequence flows 1-4 in order, and the existing `resume-workflow` entry point should point at or become that
complete flow without duplicating divergent instructions.

## Acceptance Criteria **[REQUIRED]**

- [ ] New `complete-resume-flow` skill exists, or `resume-workflow` is intentionally renamed/retained as the
      composite guide with explicit references to flows 1-4.
- [ ] The composite flow calls the smaller flows in order: `prepare-base-resume` -> `ingest-job` ->
      `tailor-resume` -> `finalize-resume`.
- [ ] `resume-workflow` no longer contains a divergent copy of per-stage gates; smaller flow skills are the
      source of truth for stage details.
- [ ] Plugin skill slug tests are updated for the new flow skills and any renamed/retained workflow skill.
- [ ] README and plugin README document the split and the repeated-use path: Flow 1 once, then Flows 2/3/4
      many times.
- [ ] Integration coverage proves Flow 1 can run once and two different jobs can run through Flow 2 + Flow 3
      + Flow 4 without rerunning Flow 1.
- [ ] Full gate green: ruff, mypy, pytest, and plugin markdown tests.

## Implementation Notes **[REQUIRED]**

### Technical Approach
- Keep the composite guide short; it should delegate to the four smaller flows.
- If new code-owned composite capabilities were added in earlier tasks, include them in interface parity
  tests. If the split is skill-only, verify primitive surfaces are unchanged.
- Reconcile docs in one pass after the individual flow skills land.

### Dependencies
- [[RIT-T-0170]], [[RIT-T-0171]], [[RIT-T-0172]], and [[RIT-T-0173]].

### Risk Considerations
- Avoid two sources of truth for the flow order.
- Keep the release close-out focused; do not bundle unrelated refactors.

### Recommended Agent
`opus + medium` — integration and docs/tests across skill suite and repo-level gates.

## Verification Steps **[REQUIRED]**

- [ ] `uv run --no-sync ruff check packages tests plugins`
- [ ] `uv run --no-sync mypy packages`
- [ ] `uv run --no-sync pytest`
- [ ] Plugin skill markdown tests pass.
