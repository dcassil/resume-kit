## Implementation Notes **[CONDITIONAL: Technical Task]**

### Recommended Agent
`opus + medium` — Two skills; `inject-keywords` is genuinely new and must encode the truth-gated,
no-fabrication editing loop precisely (this is the safety-critical replacement for LLM rewrite).
`update-terminology` is a careful rename preserving RIT-I-0010 behavior. No engine code, but the truth
posture wording is load-bearing → medium.

### Technical Approach
- Read the existing `align-terminology/SKILL.md` (copy → `update-terminology`, adjust name/self-refs + add
  gate) and `align-resume/SKILL.md` (for the tailoring intent it replaces), plus `identify-resume-gaps`
  (injectable vs non-injectable), `validate-resume-truth`, and `resume-to-json` (working-dir + subagent
  conventions).
- `inject-keywords` loop: read injectable keywords → agent adds them where the candidate genuinely
  demonstrates them (skills/summary, drawn from master/evidence) → `validate-resume-truth` gate → revert
  any flagged → report + re-score. Mirror the truth posture used in `manage-synonyms`/`align-terminology`
  (concrete DO/DON'T, gaps-stay-gaps).
- Use the shared gate convention from RIT-T-0080 if present; else inline it consistently.

### Dependencies
- Depends on: RIT-I-0010 terminology surfaces (exist) + `identify-resume-gaps`. Coordinate gate wording
  with RIT-T-0080. File-disjoint from RIT-T-0077/0078/0080. Blocks: RIT-T-0081.

### Risk Considerations
- **Fabrication**: `inject-keywords` must NEVER add a non-injectable/absent keyword; truth gate is
  mandatory and its failure reverts the change. Make this unmistakable.
- **Overlap with update-terminology**: keep them distinct (add-true-keyword vs mirror-wording).
- **Rename breakage**: update `update-terminology`'s internal self-references; cross-links fixed in 0081.
