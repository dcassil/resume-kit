### Technical Approach
- Read the RIT-T-0077 result (the new `check-ats-structure` CLI/MCP names + output shape), and the sibling
  skills (`check-resume-ats`, `check-resume-job-match`, `identify-resume-gaps`, `resume-to-json`,

- `check-ats-structure` presents ONLY structure; `check-keyword-match` presents ONLY keyword coverage +
  matched/missing (slice the tool output; ignore section_completeness/composite).
