# End-to-end edit-loop integration test + README reconcile + version bump

## Parent Initiative

[[RIT-I-0015]]

## Objective **[REQUIRED]**

Prove the redesigned edit → verify → export loop end-to-end with an integration test, reconcile README /
cross-surface tests with the new commands, and cut a version bump. This is the closing task that verifies
the initiative's exit criteria against real fixtures — mirroring how prior phases closed (e.g. RIT-T-0081,
RIT-T-0094).

## Context

The prior tasks add corrected truth semantics, a reason enum, feedback/evidence surfaces, and a hard-gated
orchestrator with rewired skills. This task ties them together with an executable end-to-end test and
brings docs/version into line.

## Acceptance Criteria **[REQUIRED]**

- [ ] Integration test over a real resume/job fixture that exercises an edit session in all three modes
      and asserts: (a) the hard gate **refuses** a bulk unlogged write; (b) a per-change accept/modify/
      reject loop writes only logged changes and appends `EditFeedback` records; (c) `add-evidence
      --confirmed` lets a new-but-true skill pass `validate-truth` as `USER_CONFIRMED` (not
      `CONTRADICTED`); (d) a genuinely refuted claim is still `CONTRADICTED`; (e) export runs clean after.
- [ ] Negative-path assertions: applying an unlogged change and applying a truth-failing accepted change
      both fail with the right machine-readable errors / exit codes.
- [ ] Cross-surface parity tests extended to include all new commands (`record-edit-feedback`,
      `rank-edit-candidates`, `refresh-preferences`, `add-evidence --confirmed`, the edit-session
      lifecycle) consistent with existing parity suites.
- [ ] README updated: the improve-phase orchestrated loop + mode prompt, the corrected truth semantics
      (CONTRADICTED vs UNSUPPORTED + reason_code), the new feedback/evidence commands; remove stale
      "no CLI/MCP" and any bulk hand-edit guidance.
- [ ] Version bump (root `pyproject.toml` + plugin `plugin.json` as appropriate) + a release note
      summarizing the enforced human-in-the-loop edit loop and truth-semantics fix, following the repo's
      release-commit convention.
- [ ] Full test suite green.
