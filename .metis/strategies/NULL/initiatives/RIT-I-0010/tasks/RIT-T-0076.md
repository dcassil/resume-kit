# Real-resume integration fixture + public exports for terminology alignment

## Parent Initiative **[CONDITIONAL: Assigned Task]**

[[RIT-I-0010]]

## Objective **[REQUIRED]**

Prove the initiative end-to-end on a representative resume/JD fixture and finalize public exports. The
"honest, truthful mirroring" proof: alias-satisfied JD keywords become truth-gated terminology suggestions
that mirror the employer's exact wording, applying them preserves the claim (truth passes) and reports a
deterministic delta, and no-match keywords stay gaps and can never be rewritten.

## Acceptance Criteria **[REQUIRED]**

- [ ] Integration test under `tests/integration/` on a synthetic representative resume + JD (mirror the
      RIT-T-0066/0071 fixture style; note it is synthetic): resume uses alias surface forms (e.g. `k8s`,
      `ESLint`) where the JD uses the canonical/other wording (`Kubernetes`, `linting`). Asserts:
      `analyze_terminology_alignment` yields suggestions for those (correct jd_keyword/current_wording/
      locations/canonical), exact-match keywords yield none, and a no-match keyword yields NO suggestion
      (stays a gap).
- [ ] Accept path proof: applying an accepted suggestion swaps only the surface term, `validate_resume_truth`
      still passes, and the before/after `keyword_match`/`skills_coverage` delta is deterministic (assert
      swap happened + score does not drop; direction not brittle floats).
- [ ] Adversarial (NFR-1001) end-to-end: a no-match JD keyword (absent `Terraform`) can NEVER become a
      terminology rewrite; an accepted swap never changes the underlying claim; a blocked field is never
      targeted.
- [ ] At least one SURFACE-level assertion (facade or an adapter from RIT-T-0074) producing the same
      suggestions/applied result — proving parity end-to-end.
- [ ] Public exports finalized: `TerminologyAlignment`, the analyzer, and the accept/apply capability are
      exported from their packages' `__all__` and the facade, consistent with prior phases. `ruff` +
      `mypy --strict` clean; FULL suite green.
