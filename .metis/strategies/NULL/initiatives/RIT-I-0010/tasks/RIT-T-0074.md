## Objective **[REQUIRED]**

Expose terminology alignment through the facade + all interface adapters, consistent with the Phase-5/6
capability+thin-adapter pattern (REQ-1004): analyze (list suggestions) and optionally apply an accepted
suggestion (with before/after delta). Enforce cross-surface parity (facade ≡ CLI ≡ MCP ≡ API).

## Implementation Notes **[CONDITIONAL: Technical Task]**

### Recommended Agent
`opus + medium` — Integration across facade + three adapters + the bridge-style registries, with a hard
parity requirement, following the well-established Phase-5/6 pattern. Blast radius (all surfaces) and the
analyze-vs-apply split make it more than a single-file change, but the pattern is known → medium.

### Technical Approach
- Read how an existing capability (e.g. `check_resume_ats` / `identify_resume_gaps`) is wired end-to-end
  across facade → CLI → MCP → API + how the MCP tool registry / CLI app / API router register it, and
  mirror it exactly for the new capability(ies).
- Reuse RIT-T-0072 (`analyze_terminology_alignment`) and RIT-T-0073 (accept→apply→delta) — the adapters
  are thin; no business logic in the surfaces.
- Thread the RIT-I-0009 `alias_file` param (reuse `resume_kit_facade` `use_alias_file` / the existing
  `alias_file` request field pattern) so suggestions reflect the grown index.

### Dependencies
- Depends on: RIT-T-0072 (suggestions) and RIT-T-0073 (accept/apply/delta). Both must land first.
- File-disjoint from RIT-T-0075 (plugin markdown) — can run in parallel with it once 0072/0073 are in.
- Blocks: RIT-T-0076 (integration asserts a surface).

### Risk Considerations
- **Parity drift**: adapters must delegate to ONE facade capability; enforce with a parity test.
- **Registry drift**: update the expected capability/tool sets the tests assert, or they fail.
- **Auto-apply**: keep analyze and apply separate; never apply all suggestions implicitly.

### Verification Steps
1. `uv sync --all-packages --reinstall-package resume-kit` then `uv run --no-sync pytest packages/facade packages/cli packages/mcp packages/api integrations -q`.
2. `uv run --no-sync ruff check packages && uv run --no-sync mypy packages`.
3. `uv run --no-sync pytest packages integrations plugins tests` — full suite + parity green.
