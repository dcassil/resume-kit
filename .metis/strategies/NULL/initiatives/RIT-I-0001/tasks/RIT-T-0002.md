# Create Apache-2.0 attribution ledger

## Parent Initiative

[[RIT-I-0001]] — Phase 0 — Upstream Audit of Resume-Matcher

## Objective

Phase 0 must document license and attribution obligations before any Resume-Matcher code, tests, prompts, schemas, or derived implementation are reused. Use the pinned upstream clone in ./upstream/ from task 0. Write only references/attribution.md. The deliverable must cover every subsystem intended for Reuse, Extract, or Adapt once the inventory exists, and it must also provide a clear scaffold for later extraction phases to add file-level provenance.

## Acceptance Criteria

- [ ] references/attribution.md records the same pinned upstream full commit SHA produced by task 0 and the upstream repository URL.
- [ ] references/attribution.md identifies Resume-Matcher as Apache-2.0 and summarizes concrete obligations relevant to this repo: retain notices, include applicable license text when required, mark modified files, track upstream paths and SHAs, and avoid upstream trademarks as product identity.
- [ ] references/attribution.md contains a table with columns for subsystem, classification, upstream path(s), pinned SHA, reused material type, attribution requirement, modification note, and downstream target package.
- [ ] The attribution table covers every Reuse, Extract, and Adapt subsystem identified in references/reuse-inventory.md if that file is available; if the inventory task is still pending, provide a clearly marked provisional table using the vision-named candidates and note it must be reconciled during final review.
- [ ] references/attribution.md explicitly excludes Replace/Leave-behind subsystems from reuse attribution while still noting that they were reviewed and intentionally not reused.
- [ ] No product code or non-reference documentation is modified.

If not, this task can run using the vision and initiative candidate list, with final reconciliation handled by task 3.

2. Confirm references/attribution.md includes Apache-2.0 obligations and a file/subsystem provenance table.
3. Cross-check at least three Reuse/Extract/Adapt attribution rows against actual upstream file paths under ./upstream/.
4. If references/reuse-inventory.md exists, confirm every Reuse, Extract, and Adapt row there has a corresponding attribution row.
