# Scaffold Phase 4 Packages

## Parent Initiative

[[RIT-I-0005]] — Phase 4 — Controlled Alignment

## Objective

Create the three Phase 4 workspace packages exactly as described by .metis/strategies/NULL/initiatives/RIT-I-0005/initiative.md: `packages/policy` exposing `resume_kit_policy`, `packages/evidence` exposing `resume_kit_evidence`, and `packages/alignment` exposing `resume_kit_alignment`. Use `packages/matching/pyproject.toml`, `packages/ats/pyproject.toml`, their `src/<pkg>/py.typed` layout, and their package-local `tests/` convention as the style reference. These packages are Python 3.12 `uv` workspace members via the existing `members = ["packages/*"]`; do not create package-local `tests/__init__.py` files because hyphenated package dirs use importlib test mode.

## Acceptance Criteria

- [ ] All three package directories have minimal `pyproject.toml`, `README.md`, `src/<import_name>/__init__.py`, and `src/<import_name>/py.typed` files.
- [ ] `resume-kit-policy` depends on `pydantic>=2`, `resume-kit-core`, and `resume-kit-schemas`; `resume-kit-evidence` depends on `pydantic>=2`, `resume-kit-core`, and `resume-kit-schemas`; `resume-kit-alignment` depends on `pydantic>=2`, `resume-kit-core`, `resume-kit-schemas`, `resume-kit-policy`, `resume-kit-evidence`, `resume-kit-matching`, and `resume-kit-ats`.
- [ ] Each package uses `[tool.uv.sources]` workspace dependencies matching the existing package style.
- [ ] The scaffolded `__init__.py` files are intentionally minimal; public API exports are deferred to the late export task.
- [ ] `uv sync --all-packages` can resolve the new workspace members.
