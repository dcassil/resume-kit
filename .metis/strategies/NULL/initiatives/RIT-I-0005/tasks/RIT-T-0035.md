# Implement Review Controller

## Parent Initiative

[[RIT-I-0005]] — Phase 4 — Controlled Alignment

## Objective

Implement the Phase 4 human-in-the-loop review controller as a pure state machine, not a CLI/MCP/API loop. RIT-I-0005 REQ-408 requires section-by-section review that exposes current and proposed content, change explanation, evidence for material claims, expected score impact, and decision options: approve, reject, edit, retry, reduce-freedom, increase-freedom, and skip. It must return `InterfaceResponse` with `requires_human_input` and questions using `packages/core/src/resume_kit_core/response.py` (`InterfaceResponse`, `Question`) and schema `ReviewSession` / `ReviewDecision`.

## Acceptance Criteria

- [ ] A review session can be initialized from proposed changes, evidence/provenance, and optional score impact without applying unresolved sections.
- [ ] The controller returns `InterfaceResponse.needs_input(...)` or equivalent with `requires_human_input=True` and section-specific questions when the current section is unresolved.
- [ ] Approve/reject/edit/retry/reduce-freedom/increase-freedom/skip decisions update session state deterministically.
- [ ] The controller does not advance past a section until that section has a terminal decision or an explicit retry/freedom-change action that reopens the same section.
- [ ] Non-human-in-loop mode can produce a resolved session or bypass marker that the orchestrator can include in `AlignmentResult`.
- [ ] Tests cover initialization, blocking on unresolved section, each decision action, no accidental advancement, and serialization of review state.
- [ ] No CLI input, terminal prompts, MCP tool calls, provider calls, or network calls exist in this module.

## Implementation Notes

Use `packages/alignment/src/resume_kit_alignment/review.py`. Keep it interface-agnostic: the only transport-facing type should be `InterfaceResponse` and `Question` from core. Do not call generation or apply from this module. It should be reusable by `align_resume` but remain file-disjoint. Do not edit package `__init__.py`.
