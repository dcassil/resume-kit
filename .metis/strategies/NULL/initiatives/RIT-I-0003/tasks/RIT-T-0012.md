# Extract JSON helpers and parse prompts

## Parent Initiative

[[RIT-I-0003]] — Phase 2 — Document Extraction & Parsing

## Objective

Extract the transport-free LLM response helpers and parse prompt constants into standalone modules. This supports structured parsing without coupling to LiteLLM or upstream app modules.

## Acceptance Criteria

- [ ] JSON/text helper module includes the pure response-text extraction and JSON-fence/object extraction behavior needed by structured parsing.
- [ ] Prompt module exposes `PARSE_RESUME_PROMPT` and `RESUME_SCHEMA_EXAMPLE` as pure string constants.
- [ ] Characterization tests cover fenced JSON, unfenced JSON embedded in surrounding text, generic code fences, thinking-tag stripping if included, empty content/code block behavior, and nested message content extraction.
- [ ] No concrete provider, LiteLLM, `app.*`, or network import appears in either module or tests.
- [ ] Both source files carry modified-source markers with their upstream paths and pinned SHA.
