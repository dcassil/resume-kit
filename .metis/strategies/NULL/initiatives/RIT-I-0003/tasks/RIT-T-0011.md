## Objective

Add deterministic extraction from bytes plus filename. This is the always-available no-LLM half of the parser and must stay independent of the structured parsing provider path.

## Acceptance Criteria

## Acceptance Criteria

- [ ] `parse_document` or equivalent accepts `(content: bytes, filename: str)` and returns Markdown text for PDF/DOCX inputs via MarkItDown.
- [ ] A first-class `extract_resume_text` no-LLM entrypoint returns extracted text plus structured warnings/provenance-compatible metadata for Markdown/plain text and MarkItDown-backed files.
- [ ] Plain text and Markdown inputs do not require MarkItDown conversion when a simple decode is sufficient, and invalid or empty inputs produce warnings rather than provider calls.
- [ ] Tests cover Markdown/plain text and at least one MarkItDown conversion fixture or generated fixture; all tests run without network.
- [ ] Source file carries the modified-source marker for `apps/backend/app/services/parser.py` at SHA `116f9cc3b00e1ac91734a6c2679bf41ea64a0edc`.
