# Adapt structured resume parsing behind provider protocol

## Parent Initiative

[[RIT-I-0003]] — Phase 2 — Document Extraction & Parsing

## Objective

Implement the LLM-only structured parse path as a thin adapter over `StructuredCompletionProvider`, composing deterministic text extraction, prompt constants, date restoration, schema validation, result models, warnings, confidence, and public exports.

## Acceptance Criteria

## Acceptance Criteria

## Acceptance Criteria

- [ ] `parse_resume_structured(data, filename, provider)` extracts text, calls only the injected `StructuredCompletionProvider`, restores month-inclusive dates, validates into `ResumeDocument`, and returns a parse result with confidence, warnings, and provenance.
- [ ] A text-only/no-provider path returns extracted text and a structured warning that structured parsing is unavailable rather than raising.
- [ ] Provider failures, malformed provider output, empty extracted text, and Pydantic validation failures map to warnings/reduced confidence or structured errors according to existing core taxonomy; tests assert no crashes for expected non-fatal cases.
- [ ] Provider-boundary tests use `resume_kit_core.testing.FakeStructuredCompletionProvider` only and perform no network calls.
- [ ] Public `resume_kit_document_parser.__init__` exports the text extraction entrypoint, structured parse entrypoint, and result models.
- [ ] Adapted source carries the modified-source marker for `apps/backend/app/services/parser.py` at SHA `116f9cc3b00e1ac91734a6c2679bf41ea64a0edc`.

## Implementation Notes

Recommended Agent: opus + medium
Adapt upstream `upstream/apps/backend/app/services/parser.py:144-179` without carrying over `app.llm`, `app.prompts`, `app.schemas`, `get_llm_config`, `get_model_name`, or `get_safe_max_tokens`. Build a `StructuredCompletionRequest` from `resume_kit_core.providers` with system message `You are a JSON extraction engine. Output only valid JSON, no explanations.` and prompt text from `PARSE_RESUME_PROMPT.format(schema=RESUME_SCHEMA_EXAMPLE, resume_text=markdown_text)`. Provider returns `dict[str, Any]`; then call `restore_dates_from_markdown`, validate with `resume_kit_schemas.ResumeDocument.model_validate`, and store `model_dump()` only if the result model wants a raw payload. Import and compose `text_extraction.py`, `dates.py`, `prompts.py`, and `results.py`; do not edit those modules here unless a small integration fix is unavoidable.
