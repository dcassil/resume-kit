## Implementation Notes **[CONDITIONAL: Technical Task]**

### Recommended Agent
`opus + high` — Foundational: defines the schemas + package that the other three tasks import; getting the
`EditFeedback` shape, the append-only log contract, and the workspace/umbrella wiring right is load-bearing
(a wrong schema cascades). New package scaffolding + boundary tests + umbrella packaging.

### Technical Approach
- Copy `packages/terms/pyproject.toml` as the scaffold template (change name/description/packages path).
- Put the four schemas in `resume_kit_schemas` (a new module e.g. `feedback.py`, exported) so both the
  feedback package and the plugin surfaces can share them.
- Log I/O: `append_edit_feedback(record, *, base_path=None)` + `read_edit_feedback(*, base_path=None)`
  over `learning/edit-feedback.jsonl`; JSONL; deterministic serialization (sorted keys ok). Timestamps
  are provided by callers/tests (do not call Date.now-style nondeterminism in pure functions — accept the
  timestamp as data).
- Keep the package pure/deterministic; no network, no LLM.

### Dependencies
- Depends on: RIT-I-0009 (learning/ convention), schemas. Blocks: RIT-T-0086, 0087, 0088.
- File-scope: `packages/schemas/**`, new `packages/feedback/**`, root `pyproject.toml` force-include,
  `uv.lock`, boundary test files. (Owns the package skeleton + __init__; later tasks add modules.)

### Risk Considerations
- **Schema churn**: coordinate `UserPreferenceProfile`/`CandidateFeatures`/`PreferencePair` field names with
  RIT-T-0086/0087 (they extend usage). Prefer complete-but-minimal now.
- **Append-only integrity**: reads must tolerate a missing file; appends must never rewrite prior lines.
- **Determinism**: pure functions; timestamps are inputs, not `now()`.
- **Dev-venv landmine**: reinstall umbrella (`uv sync --all-packages --reinstall-package resume-kit`) then
  run with `--no-sync`; see `.agents/work-log.md`.

### Verification Steps
1. `uv sync --all-packages --reinstall-package resume-kit` then `uv run --no-sync pytest packages/schemas packages/feedback -q`.
2. `uv run --no-sync ruff check packages && uv run --no-sync mypy packages`.
3. `uv run --no-sync pytest packages integrations plugins tests` — full suite green.
