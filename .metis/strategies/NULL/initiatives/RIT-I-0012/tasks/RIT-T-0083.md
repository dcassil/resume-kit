# Workflow wiring + once-per-session review offer (hook + marker)

## Parent Initiative **[CONDITIONAL: Assigned Task]**

[[RIT-I-0012]]

## Objective **[REQUIRED]**

Make the `review-tailored-resume` skill discoverable at the right moments: add it as an OPTIONAL,
advice-only step in the `resume-workflow` guide, and offer it ONCE PER SESSION when a session starts in an
initialized `resume-kit/` working dir (not on every skill run).

## Acceptance Criteria

## Acceptance Criteria

## Acceptance Criteria **[REQUIRED]**

- [ ] `resume-workflow/SKILL.md`: add the optional review as a step AFTER improve (inject-keywords /
      update-terminology) and BEFORE export, clearly marked **optional** and **advice-only**, referencing
      `review-tailored-resume` by slug, with its gate (needs new + original + job JSON). Do not make it a
      required step; the flow must still read correctly if it is skipped.
- [ ] Once-per-session offer: the SessionStart hook `plugins/resume-intelligence/bin/check-resume-kit.sh`
      is extended so that, WHEN `resume-kit-mcp` is present AND the current dir is an initialized
      `resume-kit/` working dir (e.g. `resume-kit/config.json` exists), it emits non-blocking
      SessionStart `additionalContext` telling the agent the optional second-agent review is available and
      to OFFER it once this session. It must still exit 0, emit valid JSON (no `jq`), and preserve the
      existing not-installed warning branch unchanged.
- [ ] Session marker: define + document the "once per session" mechanism so the offer is not repeated —
      e.g. the agent writes a marker like `resume-kit/.cache/review-offered` (or session-id-scoped) after
      offering, and the review step / workflow guide checks for it. Declining is remembered for the session
      (same marker). Keep the marker out of the way (a `.cache/`-style path) and documented in the guide.
- [ ] The offer is advice-only and never auto-runs the review; the user opts in.
- [ ] `claude plugin validate` passes; the hook runs cleanly (`bash -n` + a manual invocation in an
      initialized vs uninitialized dir behaves correctly); plugin skill suite green.

## Implementation Notes **[CONDITIONAL: Technical Task]**

### Recommended Agent
`opus + medium` — Small but the once-per-session semantics + the SessionStart hook JSON (no jq, must not
break the existing branch) need care, and the workflow-guide wording must keep the step optional without
breaking the runbook. Medium.

### Technical Approach
- Read the current `bin/check-resume-kit.sh` (two branches: installed → exit 0; not-installed → warn).
  Add, in the installed branch, a check for an initialized working dir (`[ -f resume-kit/config.json ]`)
  and emit an `additionalContext` note about the available optional review + "offer once". Keep valid JSON
  via `printf` (no jq), always `exit 0`.
- Decide the marker path + how "once per session" is keyed (a simple presence marker the agent writes on
  first offer/decline is sufficient; a session-id file is optional). Document it in `resume-workflow` and
  reference it from `review-tailored-resume` if helpful. (Coordinate the marker path with RIT-T-0082 if it
  reads it.)
- Keep the review step OPTIONAL everywhere; the pipeline is valid without it.

### Dependencies
- Depends on: RIT-T-0082 (the skill it wires) — reference its slug; if run in parallel, target the slug
  `review-tailored-resume`. File-disjoint from RIT-T-0082 (owns resume-workflow/SKILL.md + bin/ hook) and
  RIT-T-0084 (docs/dev). Do NOT edit tests/README/plugin.json (RIT-T-0082 owns those).
- Blocks: nothing.

### Risk Considerations
- **Breaking the hook**: preserve the not-installed branch + `set -euo pipefail` + valid JSON + exit 0.
- **Nagging**: the offer must be once-per-session, not per-invocation — the marker is the guard.
- **Required-step creep**: keep it optional; skipping it must not break the workflow narrative.

### Verification Steps
1. `bash -n plugins/resume-intelligence/bin/check-resume-kit.sh`; manual run with/without
   `resume-kit/config.json` present → correct JSON, exit 0.
2. `claude plugin validate plugins/resume-intelligence` passes.
3. Read-through: resume-workflow shows the optional advice-only review step + marker note.
