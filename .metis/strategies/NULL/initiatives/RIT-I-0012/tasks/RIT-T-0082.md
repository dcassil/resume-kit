# review-tailored-resume skill (subagent critique, structured findings, advice-only)

## Parent Initiative **[CONDITIONAL: Assigned Task]**

[[RIT-I-0012]]

## Objective **[REQUIRED]**

Ship the reusable, single-responsibility `review-tailored-resume` plugin skill: dispatch a SUBAGENT to
critique the (new tailored resume, original resume, job description) triple and write STRUCTURED findings
to `resume-kit/review/<session>.md`. Advice-only — it never mutates the resume. This is the shared piece
both the optional workflow step (RIT-T-0083) and the dev debug/refine loop (RIT-T-0084) build on.

## Acceptance Criteria **[REQUIRED]**

- [ ] `plugins/resume-intelligence/skills/review-tailored-resume/SKILL.md` (slug
      `review-tailored-resume`): ONE job — dispatch a subagent to critique new+original+JD and write
      findings. Frontmatter mirrors sibling skills exactly (name + block-scalar description; "Best run in
      a subagent" note as siblings use). Runs in the `resume-kit/` working dir.
- [ ] Prerequisites gate (reference `_shared/prerequisites.md`): requires the NEW/tailored resume JSON
      (working/<session>/resume.json), the ORIGINAL resume JSON, and the job JSON (config.json
      active_resume/active_job). If any missing, STOP and name the upstream skill (`resume-to-json` /
      `job-to-json`, or "run the tailoring skills first").
- [ ] Reviewer = a Task SUBAGENT by default (portable, no codex dependency). The skill notes that a
      fully-independent `codex exec` reviewer is an OPTIONAL power/dev choice, but the default path must
      work with no codex present (NFR-1201).
- [ ] Critique rubric passed to the reviewer covers: truthfulness concerns (claims not supported by the
      original), missed JD requirements, over-claims / under-claims, terminology-mirroring opportunities,
      structure/ATS readability, and an overall verdict. The reviewer is told it is ADVICE — it does not
      edit anything.
- [ ] Structured findings written to `resume-kit/review/<session>.md` with a consistent, parseable layout
      (REQ-1204): sections `## Strengths`, `## Weaknesses`, `## Truthfulness risks`, `## Missed JD
      requirements`, `## Terminology suggestions`, `## Overall verdict` — each with concrete, located
      items (point at resume section/bullet). Document the structure in the skill so the dev loop can parse
      it.
- [ ] Advice-only guarantee (NFR-1203): the skill writes ONLY under `resume-kit/review/`; it must not edit
      the resume JSON. It points the user to `inject-keywords` / `update-terminology` /
      `validate-resume-truth` to act on findings.
- [ ] Registration + docs: add `review-tailored-resume` to `EXPECTED_SKILL_SLUGS` in
      `plugins/resume-intelligence/tests/test_skill_markdown.py` (workflow/agent-driven skill — EXEMPT
      from `EXPECTED_CLI_OR_MCP`, like `manage-synonyms`/`resume-workflow`); add a row to the README
      capability map (LLM required? = No — subagent) + mention it in the README Workflow section as the
      optional review step; bump the plugin version in `.claude-plugin/plugin.json` (0.3.0 → 0.4.0).
- [ ] `claude plugin validate` passes; the plugin skill-markdown suite passes with the new slug.

## Implementation Notes **[CONDITIONAL: Technical Task]**

### Recommended Agent
`opus + medium` — Skill markdown, but the critique rubric + the advice-only/no-mutation guarantee + the
parseable findings structure are the load-bearing contract the other two tasks depend on. Also touches the
shared test/README/version files. Medium.

### Technical Approach
- Read sibling skills (`manage-synonyms`, `resume-workflow`, `validate-resume-truth`, `resume-to-json`) for
  frontmatter, subagent-dispatch phrasing, working-dir + gate conventions, and how `resume-workflow` was
  registered as a workflow-exempt slug.
- Define the subagent prompt/rubric inline; instruct the subagent to return the structured sections; the
  skill writes them to `resume-kit/review/<session>.md`.
- Keep it advice-only and single-purpose; do not add tool calls that mutate the resume.

### Dependencies
- Depends on: RIT-I-0011 (skills, gate convention, working-dir). File-disjoint from RIT-T-0083
  (resume-workflow + hook) and RIT-T-0084 (docs/dev). Owns the shared test/README/plugin.json.
- Blocks (soft): RIT-T-0083/0084 reference this skill by slug.

### Risk Considerations
- **Accidental mutation**: the skill must be unambiguously advice-only (writes only to review/). State it.
- **Findings drift**: fix the section headings so RIT-T-0084 can parse them.
- **Codex hard-dependency**: default subagent; codex only mentioned as optional.
- **Slug test**: register the new slug + workflow-exemption or the suite fails.

### Verification Steps

2. `uv run --no-sync pytest plugins -q` green (slug set + frontmatter + mapping).
3. Read-through: advice-only, gated, structured findings layout documented.
