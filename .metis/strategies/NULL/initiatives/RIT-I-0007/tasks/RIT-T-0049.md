# Scaffold the export package

## Parent Initiative

[[RIT-I-0007]] — Phase 6 — Export & Packaging

## Objective

Create the new `packages/export` workspace package for `resume_kit_export` as specified by `.metis/strategies/NULL/initiatives/RIT-I-0007/initiative.md` Detailed Design step 1. The package depends inward only on `resume_kit_schemas` and `resume_kit_core`, plus local renderer dependencies `reportlab` and `python-docx`. Define `ExportFormat` with `pdf` and `docx`, `ExportOptions`, MIME helpers, and the public `render(resume: ResumeDocument, format: ExportFormat, options: ExportOptions | None = None) -> bytes` dispatcher. The render input is `resume_kit_schemas.resume.ResumeDocument` with exact fields `personalInfo`, `summary`, `workExperience`, `education`, `personalProjects`, `additional`, `sectionMeta`, and `customSections`.

## Acceptance Criteria

- [ ] `packages/export/pyproject.toml` exists with package name `resume-kit-export`, Hatch wheel target `src/resume_kit_export`, dependencies on `resume-kit-core`, `resume-kit-schemas`, `reportlab`, and `python-docx`, and workspace sources for internal deps.
- [ ] `packages/export/src/resume_kit_export/py.typed` exists.
- [ ] `resume_kit_export.models.ExportFormat` accepts only `pdf` and `docx`; `ExportOptions` is typed and deterministic with no timestamp, locale, UUID, random, or filesystem defaults.
- [ ] `resume_kit_export.render.render(...)` dispatches by `ExportFormat` without importing any transport package or LLM/provider dependency.
- [ ] Package-local model/dispatch tests cover valid formats, invalid formats, MIME mapping, and importability of the scaffold without invoking missing renderer behavior.

## Implementation Notes

Follow the leaf package style in `packages/matching/pyproject.toml`. Keep `__init__.py` conservative at this stage: export `ExportFormat`, `ExportOptions`, and `render`; defer adding `render_pdf`/`render_docx` to the late public-exports task after renderer files exist. Do not add any facade or transport imports here.
