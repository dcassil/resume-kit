# Wire public exports for export

## Parent Initiative

[[RIT-I-0007]] — Phase 6 — Export & Packaging

## Objective

Finish public import surfaces after the implementation is stable. Update package `__init__.py` files and public-export smoke tests so `resume_kit_export`, `resume_kit_facade`, and the job-hunter bridge expose the new export symbols consistently. This is late on purpose: `packages/facade/src/resume_kit_facade/capabilities.py` and `models.py` are owned by the facade capability task; this task only edits `__init__.py` and public-export tests.

## Acceptance Criteria

- [ ] `resume_kit_export.__all__` exports `ExportFormat`, `ExportOptions`, `render`, `render_pdf`, and `render_docx`; `packages/export/tests/test_public_exports.py` verifies them.
- [ ] `resume_kit_facade.__all__` exports `ExportResumeRequest` and `export_resume`; `packages/facade/tests/test_public_exports.py` expects registry length 11 and includes `export-resume`.
- [ ] `resume_kit_job_hunter_bridge.__all__` exports `export_resume` and `export_resume_sync`; `integrations/job-hunter/tests/test_public_exports.py` verifies both are importable.
- [ ] No transport package `__init__.py` grows business exports unless already needed by existing tests; CLI/MCP/API command/tool/route registration remains covered in their own adapter tests.
