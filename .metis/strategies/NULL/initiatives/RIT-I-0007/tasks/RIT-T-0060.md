# Extend boundary and surface parity tests

## Parent Initiative

[[RIT-I-0007]] — Phase 6 — Export & Packaging

## Objective

Extend late cross-cutting tests for export per REQ-604. Update `tests/boundary/test_boundary_no_upstream_imports.py` so `packages/export` is an expected package and ReportLab/python-docx are forbidden in engine packages except the export package. Update `tests/boundary/test_interface_boundaries.py` so export is classified correctly as engine-side and still cannot import transports. Extend `tests/interface/test_surface_parity.py` so facade, CLI, MCP, and API agree on export artifact metadata.

## Acceptance Criteria

- [ ] `test_known_packages_present` in `tests/boundary/test_boundary_no_upstream_imports.py` includes `export`.
- [ ] Boundary tests forbid `reportlab` and `docx`/`python-docx` imports in engine packages other than `packages/export`, while allowing them in `packages/export` only.
- [ ] Interface boundary tests include `export` in engine package scans and continue to enforce no imports of `resume_kit_cli`, `resume_kit_mcp`, `resume_kit_api`, `resume_kit_facade` from lower engine packages as appropriate.
- [ ] Surface parity includes an `export-resume` case that compares artifact metadata across direct facade, CLI `resume-tool export`, MCP `resume_export`, and API `POST /export`; bytes may be compared by deterministic hash or signature where transport payload shapes differ.
- [ ] Parity fixtures include a non-empty `ResumeDocument` with `personalInfo`, `summary`, `workExperience`, and `additional` so export renders meaningful content.

## Implementation Notes

Keep these tests late because they touch shared global test files. For parity, normalize only comparable envelope fields and artifact metadata; avoid making every transport return identical raw byte payloads if CLI writes to `--out` and API can return binary. Use deterministic hashes for bytes if needed.
