# Fix the umbrella packaging and publish workflow

## Parent Initiative

[[RIT-I-0007]] — Phase 6 — Export & Packaging

## Objective

Make the root `resume-kit` distribution real and self-contained per REQ-605/REQ-607 in `.metis/strategies/NULL/initiatives/RIT-I-0007/initiative.md`. The current root `pyproject.toml` has `[tool.hatch.build.targets.wheel] packages = ['src/resume_kit']`, which points to a hollow non-existent target. Replace it with Hatch force-includes for every import package under `packages/*/src/resume_kit_*` and `integrations/*/src/resume_kit_*`, move third-party runtime dependencies into root base/extras, declare the umbrella `resume-tool` console script, and add Trusted Publishing configuration without running an upload.

## Acceptance Criteria

- [ ] Root `pyproject.toml` force-includes all import packages: `resume_kit_schemas`, `resume_kit_core`, `resume_kit_document_parser`, `resume_kit_job_parser`, `resume_kit_ats`, `resume_kit_matching`, `resume_kit_policy`, `resume_kit_evidence`, `resume_kit_alignment`, `resume_kit_export`, `resume_kit_facade`, `resume_kit_cli`, `resume_kit_mcp`, `resume_kit_api`, and `resume_kit_job_hunter_bridge`.
- [ ] The umbrella wheel metadata has no unresolved internal `Requires-Dist` entries such as `resume-kit-core`, `resume-kit-schemas`, or other `resume-kit-*` workspace packages.
- [ ] Root base dependencies include engine/export third-party dependencies such as `pydantic`, `markitdown`, `pdfminer.six`, `python-docx`, and `reportlab`; optional extras include `cli` with Typer, `mcp` with MCP SDK, `api` with FastAPI/uvicorn, and `all` as the union.
- [ ] Root `[project.scripts]` exposes `resume-tool = resume_kit_cli.app:app` so `pip install resume-kit[cli]` provides the command.
- [ ] PyPI metadata includes classifiers, project URLs, README long description, license file references, and includes `LICENSE`/`NOTICE` in sdist/wheel.
- [ ] `.github/workflows/publish.yml` uses PyPI Trusted Publishing/OIDC, builds distributions on version tags, and does not contain credentials or auto-run on ordinary pushes.
- [ ] README documents `uv build`, `pip install resume-kit`, extras `[cli]`, `[mcp]`, `[api]`, `[all]`, and manual Trusted Publishing/twine fallback without claiming the package has been uploaded.

## Implementation Notes

Keep per-package `pyproject.toml` files for workspace development; the umbrella shipped wheel must vendor source trees and depend only on third-party packages. Do not run publishing commands. Check built wheel metadata after `uv build` to ensure internal workspace package requirements are absent.
