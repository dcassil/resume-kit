# Add the CLI export command

## Parent Initiative

[[RIT-I-0007]] — Phase 6 — Export & Packaging

## Objective

Add a thin CLI adapter for `export-resume` in `packages/cli/src/resume_kit_cli/app.py`, using existing helpers in `packages/cli/src/resume_kit_cli/io.py` and output rendering in `packages/cli/src/resume_kit_cli/formatters.py`. The command must mirror Phase 5 transport style: build an `ExportResumeRequest`, create `CapabilityOptions` with an injected `ArtifactStore`, invoke `resume_kit_facade.capabilities`, render the canonical `InterfaceResponse`, and exit via `resume_kit_core.interface.exit_code_for`.

## Acceptance Criteria

- [ ] `resume-tool export --resume <resume.json> --format {pdf,docx} --out <path>` writes valid PDF/DOCX bytes to the requested path and exits 0 on success.
- [ ] When `--out` is omitted, the command emits a stdout-safe JSON/text/markdown response containing artifact metadata and base64-encoded bytes rather than writing binary bytes into a formatted envelope.
- [ ] CLI invalid format/input errors are surfaced as Typer or canonical facade errors with deterministic nonzero exit codes; no traceback leaks.
- [ ] CLI contract tests include help text listing `export`, successful PDF and DOCX file writes, stdout-safe base64 behavior, and JSON envelope artifact metadata.

## Implementation Notes

Use `io.load_resume` to parse `ResumeDocument`. Add only transport parsing/file-write/base64 behavior here; no rendering logic or ReportLab/python-docx imports belong in CLI files. Use `FakeArtifactStore` or another in-memory `ArtifactStore` instance locally, pass it on `CapabilityOptions.artifact_store`, then retrieve bytes after a successful facade response. Preserve existing `--output {json,text,md}` behavior for envelopes.
