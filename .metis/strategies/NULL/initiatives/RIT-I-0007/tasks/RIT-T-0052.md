# Add the export-resume facade capability

## Parent Initiative

[[RIT-I-0007]] — Phase 6 — Export & Packaging

## Objective

Add the deterministic `export-resume` facade capability over `resume_kit_export`, following the existing async capability pattern in `packages/facade/src/resume_kit_facade/capabilities.py` and request model pattern in `packages/facade/src/resume_kit_facade/models.py`. The capability must render a `ResumeDocument` to `ExportFormat`, write bytes through `resume_kit_core.storage.ArtifactStore.put(artifact_id, artifact_type, data, content_type=..., metadata=...)`, and return `resume_kit_core.response.InterfaceResponse` with `artifacts: list[ArtifactRef]`. Tests should use `resume_kit_core.testing.FakeArtifactStore`.

## Acceptance Criteria

- [ ] `ExportResumeRequest` exists in `packages/facade/src/resume_kit_facade/models.py` with `resume: ResumeDocument`, `format: ExportFormat`, optional `options: ExportOptions`, and a deterministic caller-supplied or hash-derived `artifact_id` path that does not use random/time values.
- [ ] `CapabilityOptions` carries an optional `ArtifactStore` injection point without requiring any concrete backend or provider.
- [ ] `export_resume(request, options)` renders through `resume_kit_export.render.render`, calls `ArtifactStore.put(...)`, and returns `build_success(...)` with exactly one `ArtifactRef` whose `content_type` is `application/pdf` for PDF or `application/vnd.openxmlformats-officedocument.wordprocessingml.document` for DOCX.
- [ ] `REGISTRY` contains `export-resume`; the capability never requires `provider`, ignores `no_llm`, and maps `ResumeKitError`/unexpected exceptions through the same helpers used by existing capabilities.
- [ ] Facade tests cover PDF and DOCX, artifact metadata, bytes retrievable from `FakeArtifactStore.get`, wrong-request validation, deterministic artifact ids/bytes, and no-provider execution.

## Implementation Notes

Add `resume-kit-export` as a facade dependency in `packages/facade/pyproject.toml` and `[tool.uv.sources]`. Keep raw bytes out of `InterfaceResponse.data`; transports that need bytes should pass their own store via `CapabilityOptions.artifact_store` and retrieve by returned `ArtifactRef.artifact_id`. Do not edit facade `__init__.py` here; public re-exports are handled late to avoid repeated edits.
