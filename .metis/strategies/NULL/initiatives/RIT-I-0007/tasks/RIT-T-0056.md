# Add the job-hunter export callable

## Parent Initiative

[[RIT-I-0007]] — Phase 6 — Export & Packaging

## Objective

Add a pure-library `export_resume` callable to `integrations/job-hunter/src/resume_kit_job_hunter_bridge/bridge.py`, following the existing bridge pattern over `resume_kit_facade.capabilities.REGISTRY`. The callable accepts a `ResumeDocument`, an `ExportFormat`, optional `ExportOptions`, and optional `CapabilityOptions`, delegates to `export-resume`, and returns the canonical `InterfaceResponse` carrying an `ArtifactRef`.

## Acceptance Criteria

- [ ] `export_resume(...)` and `export_resume_sync(...)` exist in `bridge.py`, delegate only to `REGISTRY['export-resume']`, and preserve the no-mutation guarantee for `ResumeDocument`.
- [ ] Bridge tests cover async and sync PDF/DOCX export, artifact metadata, bytes retrievable from an injected `FakeArtifactStore`, no-provider execution, and input non-mutation.
- [ ] The bridge remains transport-free: no Typer, MCP SDK, FastAPI, HTTP client, filesystem storage backend, or renderer-specific imports are introduced.
- [ ] Public package re-export from `integrations/job-hunter/src/resume_kit_job_hunter_bridge/__init__.py` is intentionally deferred to the late public-exports task.

## Implementation Notes

Import only `resume_kit_core`, `resume_kit_facade`, `resume_kit_schemas`, and `resume_kit_export` value types as needed. Keep sync wrappers using the existing `_run` helper. Do not write files in job-hunter state and do not add API/CLI-specific base64 or path behavior to the bridge.
