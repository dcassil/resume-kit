# Add the clean-venv install proof

## Parent Initiative

[[RIT-I-0007]] — Phase 6 — Export & Packaging

## Objective

Add the REQ-606 proof that the umbrella wheel is installable outside the `uv` workspace. The test must build the root wheel, create a fresh throwaway virtualenv with no workspace sources on `PYTHONPATH`, install `resume-kit[cli]` from the built artifact, then assert `import resume_kit_facade` and `resume-tool --help` succeed. This is separate from packaging so wheel failures are isolated.

## Acceptance Criteria

- [ ] A dedicated packaging/install test builds or consumes the umbrella wheel from `dist/` and installs it into a temporary virtualenv using `python -m pip install '<wheel>[cli]'`.
- [ ] The test runs in an environment that does not resolve internal packages through `[tool.uv.sources]` or the repository checkout.
- [ ] The test asserts `python -c 'import resume_kit_facade; import resume_kit_export'` succeeds inside the clean venv.
- [ ] The test asserts `resume-tool --help` succeeds inside the clean venv and lists the `export` command.
- [ ] The test is deterministic, no-network when dependencies are already cached, and can be skipped only behind a clearly documented local marker/env gate if CI runtime requires it.

## Implementation Notes

Use `subprocess.run` with explicit `sys.executable`, `venv`, and a sanitized environment. If the test needs a marker, avoid editing root pytest config unless already covered; prefer `pytest.mark.skipif` keyed to an env var for optional slow behavior. Do not modify packaging files in this task.
