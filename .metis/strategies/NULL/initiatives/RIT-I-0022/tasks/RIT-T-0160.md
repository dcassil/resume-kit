# T3: Wire workflow branch + configurable threshold and required-coverage trigger

## Parent Initiative **[CONDITIONAL: Assigned Task]**

[[RIT-I-0022]]

## Objective **[REQUIRED]**

Wire the interview into the end-to-end flow: after the existing second scoring, if the score is still low
OR a required must-have is uncovered, OFFER the `interview-missing-job-description` skill; on termination,
hand back to the existing final-refinement step. Add the configurable trigger (threshold + required-coverage)
to config. This is glue + one small config addition — no new engine, and no behavior change for users who
decline.

## Backlog Item Details **[CONDITIONAL: Backlog Item]**

N/A — assigned to initiative RIT-I-0022.

## Acceptance Criteria **[REQUIRED]**

- [ ] The `resume-workflow` guide gains the explicit branch: after second scoring → if `overall < threshold`
      OR required-coverage incomplete → OFFER the interview (opt-in) → after accepted answers, add evidence →
      run keyword update → re-score → on termination, proceed to final refinement. Decline → proceed to final
      refinement exactly as today.
- [ ] The trigger is CONFIG-DRIVEN: a threshold value (default ≈70) and the required-coverage condition are
      read from the existing project config schema (reuse RIT-T-0091's config contract; add fields minimally,
      do not fork a new config surface).
- [ ] The gate fires on BOTH conditions (overall score below threshold OR any required requirement
      uncovered) — documented and reflected wherever the "still low" hint is surfaced at the scoring step.
- [ ] The offer is strictly opt-in; no user who declines sees any changed behavior versus today.
- [ ] Guide/flow docs updated so the one obvious order is clear (…→ check-job-match → [interview?] →
      perfect/refine → export), consistent with the existing resume-workflow runbook.
- [ ] If any config field is added: `ruff`/`mypy`/tests green for the config-owning package; otherwise
      docs-only changes verified for internal-link/reference correctness.
