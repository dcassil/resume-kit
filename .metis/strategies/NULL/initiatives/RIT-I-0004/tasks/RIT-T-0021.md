# Build Provider-Injected Job Description Parser

## Parent Initiative

[[RIT-I-0004]] — Phase 3 — Matching & Deterministic Analysis

## Objective

Implement `job-parser` as the only LLM path in Phase 3: structured job keyword extraction through the core provider Protocol plus a deterministic raw-text fallback.

## Acceptance Criteria

## Acceptance Criteria

## Acceptance Criteria

- [ ] `resume_kit_job_parser.parse` exposes a provider-injected parse/extract function that returns canonical `JobDescription`.
- [ ] Structured path uses `StructuredCompletionProvider` and `StructuredCompletionRequest`; tests use `FakeStructuredCompletionProvider` only.
- [ ] No-provider fallback returns a `JobDescription` with raw text and deterministically extractable title/company/keyword hints where feasible.
- [ ] Malformed provider output produces a safe fallback or warning behavior without network calls or concrete provider imports.
