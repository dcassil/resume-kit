# Add Minimal Analysis Result Schemas

## Parent Initiative

[[RIT-I-0004]] — Phase 3 — Matching & Deterministic Analysis

## Objective

Add only the missing cross-package result models needed for explainable job match, resume selection, and version comparison so matching code can reuse canonical schemas instead of defining local duplicates.

## Acceptance Criteria

## Acceptance Criteria

## Acceptance Criteria

- [ ] `resume_kit_schemas.analysis` exposes minimal new models for dimension-level match evidence, explainable job-match reports, ranked variant selections, and deterministic comparison deltas.
- [ ] Existing `ATSScore`, `KeywordGapAnalysis`, `JobDescription`, and `AnalysisReport` remain backward compatible.
- [ ] New models are exported from `resume_kit_schemas.__init__` and covered by schema tests for validation bounds/defaults.

## Implementation Notes

Recommended Agent: opus + high. Touch schemas once and serialize all schema work here. Prefer compact names such as `MatchDimensionScore`, `JobMatchReport`, `ResumeVariantScore`, `ResumeSelectionResult`, `ScoreDelta`, and `ResumeComparisonResult` only if `AnalysisReport` is insufficient. Do not add ATS or keyword-gap duplicates. These models are New, not upstream-derived, so no modified-source marker is required; note in tests that they compose existing ATS and keyword models.
