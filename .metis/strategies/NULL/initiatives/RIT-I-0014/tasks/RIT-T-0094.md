# End-to-end ingest integration test + README/tests reconcile + version bump

## Parent Initiative

[[RIT-I-0014]]

## Objective **[REQUIRED]**

Prove the redesigned ingest pipeline end-to-end with an integration test, reconcile README and cross-surface tests with the new commands, and cut a version bump. This is the closing task that verifies the initiative's exit criteria against real fixtures.

## Context

The prior tasks add commands, a gate, and rewritten skills. This task ties them together with an executable end-to-end test over real `.docx`/`.pdf` fixtures and brings docs/version in line — mirroring how prior phases closed with an integration + reconcile + release task (e.g. RIT-T-0081, RIT-T-0059).

## Acceptance Criteria

## Acceptance Criteria **[REQUIRED]**

- [ ] Integration test that, over a real `.docx` (and a `.pdf`) fixture, exercises: `init` → `extract-text` (deterministic, no extras) → construct a faithful `ResumeDocument` → `validate-faithfulness` **passes** → `set-active` records pointer + source path → downstream `check-ats-structure`/`match` still run clean.
- [ ] Negative-path assertion: a deliberately lossy `ResumeDocument` (dropped bullet / added fabricated line) makes `validate-faithfulness` **fail** with a non-zero exit and the right finding codes.
- [ ] `job-to-json` equivalent covered for a job fixture.
- [ ] Cross-surface parity tests extended to include the new commands (`extract-text`, `init`, `set-active`, `validate-faithfulness`) consistent with existing parity suites.
- [ ] README updated: working-dir/config contract, the new commands, and the corrected extraction story; remove any remaining stale ingest guidance.
- [ ] Version bump (root `pyproject.toml` + plugin `plugin.json` as appropriate) and a release note summarizing the deterministic ingest boundary, following the repo's release-commit convention.
- [ ] Full test suite green.
