# Add Interface Boundary Tests

## Parent Initiative

[[RIT-I-0006]] — Phase 5 — Interfaces

## Objective

Add the late architecture and dependency-boundary tests required by RIT-I-0006 NFR-502 and NFR-503. Existing tests/boundary/test_boundary_no_upstream_imports.py currently treats fastapi as forbidden across all packages and has a fixed known package set; update it carefully now that packages/facade, packages/cli, packages/mcp, and packages/api are intentional Phase 5 packages. The boundary must enforce engine packages import no interface package, and engine packages contain none of Typer/click, mcp, FastAPI, uvicorn, or httpx dependencies.

## Acceptance Criteria

- [ ] The known packages boundary includes core, schemas, document-parser, matching, ats, job-parser, policy, evidence, alignment, facade, cli, mcp, and api.
- [ ] Boundary tests allow FastAPI only in packages/api, Typer/click only in packages/cli, and mcp only in packages/mcp; these heavy deps remain forbidden in schemas, core, document-parser, job-parser, ats, matching, policy, evidence, alignment, and facade source files.
- [ ] Engine source files do not import resume_kit_cli, resume_kit_mcp, resume_kit_api, resume_kit_facade, or resume_kit_job_hunter_bridge.
- [ ] Engine pyproject.toml files do not declare typer, click, mcp, fastapi, uvicorn, httpx, starlette, or requests as dependencies.
- [ ] Interface packages may import facade/core/schemas as needed, but facade does not import CLI, MCP, API, plugin, or job-hunter bridge code.
- [ ] The tests continue to forbid upstream app.*, litellm, openai, anthropic, sqlalchemy, and persistence/web framework leaks where inappropriate.
- [ ] Full boundary test suite passes without requiring network or importing upstream.

## Implementation Notes

Scan files as text like existing boundary tests to avoid import side effects. Include integrations/job-hunter/src in the facade/no-transport direction checks where relevant, but do not require integrations to be a workspace package.
