# Implement Job Hunter Bridge

## Parent Initiative

[[RIT-I-0006]] — Phase 5 — Interfaces

## Objective

Implement integrations/job-hunter as the typed library bridge required by RIT-I-0006 REQ-506. This bridge is not a transport server and must not mutate job-hunter state; it simply offers stable Python callables that job-hunter can import to analyze a resume for a job, align a resume for a job, validate truth, and build candidate evidence by delegating to resume_kit_facade and returning canonical InterfaceResponse payloads with resume_kit_schemas data.

## Acceptance Criteria

- [ ] integrations/job-hunter contains a typed import package, py.typed marker, minimal pyproject.toml or equivalent local typing configuration, README, and tests.
- [ ] Bridge functions include analyze_resume_for_job, align_resume_for_job, validate_truth, and build_evidence or equivalently named stable callables documented in README; each returns InterfaceResponse containing canonical schema data rather than bridge-local DTOs.
- [ ] The bridge delegates to resume_kit_facade for check-resume-ats, check-resume-job-match, identify-resume-gaps, align-resume, validate-resume-truth, and build-candidate-evidence as appropriate.
- [ ] The bridge never imports or writes job-hunter application state, storage, queues, HTTP clients, CLIs, MCP, FastAPI, or Typer.
- [ ] No-LLM deterministic bridge tests pass without network or provider configuration.
- [ ] Provider-requiring align behavior without provider returns the same structured provider-not-configured error unless no_llm is explicitly requested.
- [ ] Tests assert input objects are not mutated and artifact/question/provenance fields are preserved in returned InterfaceResponse values.

## Implementation Notes

Use integrations/job-hunter/src/resume_kit_job_hunter_bridge/ as the import package to avoid hyphenated import names. Because root workspace membership is packages/*, verify with PYTHONPATH=integrations/job-hunter/src unless the implementer intentionally adds this integration to the workspace in a serialized scaffold change. Keep it pure library code over facade request models and options.
