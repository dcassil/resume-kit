# Implement FastAPI Routes

## Parent Initiative

[[RIT-I-0006]] — Phase 5 — Interfaces

## Objective

Implement packages/api as a thin FastAPI adapter over resume_kit_facade. RIT-I-0006 REQ-504 requires one REST endpoint per exposed capability, reusing resume_kit_schemas domain models and surfacing InterfaceResponse with warnings, errors, requires_human_input, questions, provenance, and artifacts. Endpoints should cover extract-resume, extract-job-description, check-resume-ats, check-resume-job-match, select-best-resume, compare-resume-versions, identify-resume-gaps, align-resume, validate-resume-truth, and build-candidate-evidence.

## Acceptance Criteria

- [ ] resume_kit_api exposes a FastAPI app object with exactly one route per Phase 5 capability and no deferred Phase 6 routes.
- [ ] Routes validate request bodies into facade request models and call only resume_kit_facade; no route imports document-parser, job-parser, ats, matching, evidence, or alignment directly.
- [ ] Responses use the canonical InterfaceResponse structure and do not collapse warnings into errors or questions into plain strings.
- [ ] No-LLM deterministic route tests pass using FastAPI TestClient/httpx in-process with no network and no LLM.
- [ ] Provider-requiring route calls without a configured provider return a structured provider-not-configured InterfaceResponse error and an appropriate deterministic HTTP status policy documented in tests.
- [ ] align-resume handles the async engine path correctly from FastAPI and surfaces human-in-loop requires_human_input/questions without running an interactive loop.
- [ ] No persistence, auth, async job queue, retention, logging of resume/job content, or provider SDK integration is added.

## Implementation Notes

Use app.py for create_app/app construction, routes.py for route registration, and models.py only for transport request wrappers that are not already covered by facade models. Prefer returning InterfaceResponse models/dicts directly so FastAPI handles JSON encoding. Keep uvicorn only as package dependency/optional run target; tests should use TestClient. Do not import Typer or mcp.
