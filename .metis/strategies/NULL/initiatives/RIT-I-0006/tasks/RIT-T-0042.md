# Implement MCP Tool Server

## Parent Initiative

[[RIT-I-0006]] — Phase 5 — Interfaces

## Objective

Implement packages/mcp as a thin official MCP Python SDK server over resume_kit_facade. RIT-I-0006 requires these stable MCP tool names: resume_extract, job_description_extract, resume_check_ats, resume_check_job_match, resume_select_best, resume_compare_versions, resume_identify_gaps, resume_align, resume_validate_truth, and candidate_evidence_build. The server must return structured JSON InterfaceResponse payloads with warnings separate from errors, requiresHumanInput/questions surfaced structurally, and provenance/artifacts preserved.

## Acceptance Criteria

- [ ] The MCP server registers exactly the 10 stable tool names from the initiative and no unbuilt Phase 6 capabilities.
- [ ] Each tool validates input into transport-agnostic facade request models, calls only resume_kit_facade, and returns InterfaceResponse.model_dump(mode="json", by_alias=True if aliases are introduced) or an equivalent stable JSON dict.
- [ ] Tool outputs preserve data, warnings, errors, requires_human_input/requiresHumanInput, questions, provenance, and artifacts without MCP-local result-shape definitions.
- [ ] No-LLM deterministic tool tests pass without any network, server socket, or concrete LLM provider.
- [ ] Provider-requiring tool calls without a configured StructuredCompletionProvider return the facade/core provider-not-configured structured error.
- [ ] align tool handling awaits the async facade/engine path and tests cover human-in-loop requires_human_input output without advancing review state.
- [ ] MCP tests call handlers directly or through an in-memory MCP SDK session; they do not open a network port.

## Implementation Notes

Use the official mcp package from packages/mcp/pyproject.toml. Keep a direct handler registry in tools.py so tests can call handlers without stdio/network. server.py should build and expose the SDK server object. If the SDK uses decorators, keep the decorated functions as thin wrappers over the handler registry. Do not import Typer, FastAPI, uvicorn, or CLI/API code.
