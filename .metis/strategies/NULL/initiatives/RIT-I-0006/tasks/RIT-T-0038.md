# Extend Core Interface Substrate

## Parent Initiative

[[RIT-I-0006]] — Phase 5 — Interfaces

## Objective

Implement the load-bearing shared adapter substrate required by .metis/strategies/NULL/initiatives/RIT-I-0006/initiative.md REQ-501 in packages/core. Existing ground truth is packages/core/src/resume_kit_core/response.py, which already defines InterfaceResponse, Question, and ProvenanceRef, and packages/core/src/resume_kit_core/errors.py, which already defines ErrorCode, WarningCode, CoreError, CoreWarning, and ResumeKitError. Extend this substrate with stable interface result mapping helpers, a provider-not-configured error code, and an exit-code map that every transport will reuse; do not add Typer, MCP, FastAPI, uvicorn, or httpx to core.

## Acceptance Criteria

## Acceptance Criteria

## Acceptance Criteria

- [ ] Core exposes a single result-shaping substrate over InterfaceResponse so callers can build success, failure, provider-not-configured, human-input-required, and exception-mapped responses without inventing transport-local envelopes.
- [ ] ErrorCode contains a stable provider-not-configured code distinct from generic provider unavailable errors, and tests assert its serialized value is stable.
- [ ] A deterministic exit-code mapping exists for ok, invalid input/validation failure, provider not configured/provider unavailable, human input required, and internal/unknown errors; warnings alone do not produce a non-zero exit code.
- [ ] Mapping helpers preserve warnings, errors, requires_human_input, questions, provenance, and artifacts separately in the InterfaceResponse envelope.
- [ ] Unit tests cover success mapping, strict warning handling if supported by the helper, provider-not-configured mapping, ResumeKitError mapping, generic exception mapping, human-input mapping, and exit-code selection.
- [ ] No heavy interface dependency is added to packages/core/pyproject.toml or imported from any core source file.

## Implementation Notes

Prefer a new packages/core/src/resume_kit_core/interface.py for mapping helpers and exit-code constants so response.py and errors.py remain small; edit errors.py only for the new ErrorCode value. Use existing InterfaceResponse.success, InterfaceResponse.failure, InterfaceResponse.needs_input, CoreError, CoreWarning, ErrorCode, ResumeKitError, ArtifactRef, ProvenanceRef, and Question. Leave packages/core/src/resume_kit_core/__init__.py exports to the late public-export task unless tests need submodule imports. Keep all code provider- and transport-agnostic.
