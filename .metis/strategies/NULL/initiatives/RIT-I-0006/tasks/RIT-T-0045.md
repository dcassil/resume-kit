# Author Resume Intelligence Skills

## Parent Initiative

[[RIT-I-0006]] — Phase 5 — Interfaces

## Objective

Create the markdown agent skills under plugins/resume-intelligence required by RIT-I-0006 REQ-505. The repo currently has no plugin skill files under plugins/ or integrations/ to mirror, so infer a clean Codex-style SKILL.md format from the installed skill convention: front matter with name and description, then concise operational instructions. Skills should tell an agent how to invoke the CLI resume-tool commands or the stable MCP tools, not reimplement resume intelligence logic in markdown.

## Acceptance Criteria

- [ ] plugins/resume-intelligence contains markdown skill definitions covering exactly the 10 exposed Phase 5 capabilities and no deferred Phase 6 capabilities.
- [ ] Each skill names the corresponding CLI command and MCP tool: extract/resume_extract, extract-job/job_description_extract, check-ats/resume_check_ats, match/resume_check_job_match, select/resume_select_best, compare/resume_compare_versions, identify-gaps/resume_identify_gaps, align/resume_align, validate-truth/resume_validate_truth, and build-evidence/candidate_evidence_build.
- [ ] Skill instructions emphasize that interfaces are thin adapters over the engine/facade and that agents must not invent facts, bypass evidence, or create business rules in prompt text.
- [ ] Skills document no-LLM deterministic usage and the expected provider-not-configured structured error for LLM-requiring paths without a configured provider.
- [ ] A lightweight structure test verifies every SKILL.md has front matter, a description, references to either resume-tool or the stable MCP tool name, and no mention of unbuilt Phase 6 capabilities.
- [ ] No runtime dependency, Python package, provider SDK, network behavior, or generated resume content is added under plugins/resume-intelligence.

## Implementation Notes

A coherent grouping is acceptable, but one skill directory per capability under plugins/resume-intelligence/skills/<capability>/SKILL.md is easiest to lint and mirrors installed skill layout. Include a top-level README.md for capability mapping. Keep markdown procedural and short: inputs, preferred deterministic mode when applicable, CLI/MCP invocation shape, expected InterfaceResponse fields, and safety notes.
