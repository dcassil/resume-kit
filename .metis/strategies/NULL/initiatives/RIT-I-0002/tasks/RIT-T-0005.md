# Scaffold Phase 1 workspace packages

## Parent Initiative

[[RIT-I-0002]] — Phase 1 — Clean Core & Canonical Schemas

## Objective

Create the minimal installable package skeletons for Phase 1 only: `packages/core` and `packages/schemas`. The root `pyproject.toml` already declares `[tool.uv.workspace] members = ["packages/*"]`; preserve existing ruff, mypy strict, and pytest settings while adding only what is required for these two packages to install and import. This task must not implement schemas, protocols, matching, scoring, ATS, parsing, export, CLI, MCP, API, persistence, or frontend behavior.

## Acceptance Criteria

## Acceptance Criteria

## Acceptance Criteria

- [ ] `packages/core` and `packages/schemas` exist as installable src-layout Python packages for Python 3.12+ with `py.typed` markers.
- [ ] Package import names are stable: `resume_kit_core` and `resume_kit_schemas`.
- [ ] Root workspace config still includes `packages/*`; no Phase 2+ package directories are created.
- [ ] Each package has a minimal `pyproject.toml`, `README.md`, `src/.../__init__.py`, and package-local `tests/` directory.
- [ ] `uv run python -c "import resume_kit_core, resume_kit_schemas"` succeeds after install/sync.
- [ ] No `app.*` upstream imports are introduced anywhere under `packages/`.

### Technical Approach
Use Hatchling to match the root build backend. Keep skeleton files intentionally minimal so downstream package agents own implementation. Suggested dependency shape: `packages/schemas` depends on `pydantic>=2`; `packages/core` depends on `pydantic>=2` and the workspace `resume-kit-schemas` package if needed. Do not copy code from `./upstream/` in this task. If a lockfile is generated by `uv`, include it in this task's changes.

### Constraint (teamwork orchestration)
Implementing agent WRITES FILES ONLY. Do NOT run git (no add/commit/branch/push). You MAY run
package-local verification for your own package only (e.g. `uv run pytest packages/<x>`,
`uv run mypy packages/<x>`); do NOT run repo-wide verification that could race a concurrent agent.
`uv` (0.12.x) and Python 3.12 are installed. Donor code is read-only at ./upstream/apps/backend/app/.
Assume zero prior context beyond this document.
