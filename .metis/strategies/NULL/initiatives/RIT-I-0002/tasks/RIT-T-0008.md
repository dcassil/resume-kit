# Add Phase 1 boundary and integration quality gates

## Parent Initiative

[[RIT-I-0002]] — Phase 1 — Clean Core & Canonical Schemas

## Objective

Add repo-level tests that prove Phase 1 delivered only the clean core and canonical schema foundation. This task should validate package integration and architectural boundaries without taking ownership of implementation files in `packages/core` or `packages/schemas`. If failures expose package bugs, route fixes back to the owning package task rather than patching those package files here.

## Acceptance Criteria

- [ ] A repo-level boundary test asserts only `packages/core` and `packages/schemas` exist under `packages/` for Phase 1.
- [ ] A repo-level import test imports the public `resume_kit_core` and `resume_kit_schemas` surfaces together, including `InterfaceResponse` parameterized or instantiated with a schema payload.
- [ ] A boundary test scans `packages/` and fails on upstream `app.*` imports, concrete provider imports such as `litellm`, web/API imports such as `fastapi`, persistence imports such as `sqlalchemy`, and Phase 2+ package names or directories.
- [ ] A workspace/package metadata test confirms both packages are uv workspace members through the root `packages/*` pattern and have `py.typed` markers.
- [ ] Full local quality commands are documented and pass: ruff, strict mypy for both packages, and pytest for package and repo-level tests.
- [ ] No implementation behavior is added for matching, scoring, ATS, alignment, parsing, export, persistence, CLI, MCP, API, or frontend.

## Implementation Notes

### Execution profile
**Recommended Agent: sonnet+medium**

### Files this task may write
- `tests/`

### Dependencies
[[RIT-T-0006]], [[RIT-T-0007]]

### Technical Approach
Place tests under root `tests/`, for example `tests/test_phase1_boundaries.py` and `tests/test_phase1_imports.py`. Use standard library file scanning/TOML parsing available in Python 3.12 (`tomllib`) rather than adding new dependencies. Keep these tests deterministic and network-free. Do not edit `packages/core/`, `packages/schemas/`, or `references/attribution.md` in this task.

### Constraint (teamwork orchestration)
Implementing agent WRITES FILES ONLY. Do NOT run git (no add/commit/branch/push). You MAY run
package-local verification for your own package only (e.g. `uv run pytest packages/<x>`,
`uv run mypy packages/<x>`); do NOT run repo-wide verification that could race a concurrent agent.
`uv` (0.12.x) and Python 3.12 are installed. Donor code is read-only at ./upstream/apps/backend/app/.
Assume zero prior context beyond this document.

## Verification Steps

1. uv run ruff check packages tests
2. uv run mypy packages/core packages/schemas
3. uv run pytest packages/core packages/schemas tests
4. rg "from app|import app" packages && exit 1 || true
